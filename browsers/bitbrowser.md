# 比特浏览器怎么样？免费 10 个窗口、套餐价格与使用方式

[返回产品总览](../README.md) · 核验日期：2026-10-27

比特浏览器把浏览器环境、代理、分组和自动化放在同一个客户端中管理。对于个人维护多个电商、社媒或工作账号的场景，可以从免费窗口开始，把每个账号的登录状态和网络配置分别保留下来，再根据环境数量和成员需求升级套餐。

## 免费 10 个窗口，可以覆盖哪些工作量

官方免费价格卡列出的额度是 10 个环境、1 个成员，每日打开 50 次、每日最多创建 20 个环境，并列有窗口同步、Local API 和 RPA。这里的 10 个名额用于保留环境；50 次统计一天内的打开操作，两项需要分别计算。[免费价格卡](https://www.bitbrowser.net/price)

例如，一个人保留 8 个工作环境，每个每天打开 3 次，合计是 24 次，数量与打开频次都在上述范围内。如果同样 8 个环境每天各重开 8 次，就会达到 64 次，需要考虑更高的打开额度。这是按套餐数字计算的例子，不是性能测试结果。

## 从免费版升到付费版，买到的是什么

中国站公开列出的月付方案包括 50 个窗口、2 个员工 50 元/月；100 个窗口、4 个员工 75 元/月；200 个窗口、8 个员工 125 元/月。这些是人民币月付口径，适合拿来估算环境增加后的基础软件成本。[中国站价格说明](https://www.bitbrowser.cn/price)

英文价格页还把环境与 Cookie 导出、代理批量导出、分享转移和回收站等列在付费附加功能中。因此，准备迁移大量资料或向成员交接窗口时，要把导出与协作需求一并考虑；浏览器名额只是购买条件之一。

## 把账号、代理和常用入口放进同一个窗口

建议按业务给窗口命名，例如“客户 A—广告后台”或“店铺 B—客服”。以后从窗口列表进入对应环境，能减少在多个网站后台之间切换时选错账号的情况。

1. 从[官方下载页](https://www.bitbrowser.cn/download)安装客户端，创建一个浏览器窗口，填好名称、分组和启动页面。
2. 在窗口代理配置中填写已有代理的协议、主机、端口及认证信息，使用连接检测查看当前代理是否连通。[代理设置说明](https://www.bitbrowser.cn/proxy-setting)
3. 打开窗口后登录对应账号，后续继续使用同一个环境；不要为了区分账号而反复覆盖同一个窗口的资料。

已有其他浏览器的环境时，可用[批量导入教程](https://www.bitbrowser.cn/blog/how-to-migrate-browser-profiles-to-bitbrowser)整理窗口信息、Cookie 和代理。迁入后先用少量环境确认账号对应关系，再处理剩余记录。

## RPA、Local API 和 MCP 怎样分工

RPA 适合编排重复的页面步骤；Local API 便于程序管理窗口并连接自动化框架。比特浏览器的[Local API 介绍](https://www.bitbrowser.cn/local-api)说明了环境程序化管理及 Selenium、Puppeteer 等接入方式。

如果希望由支持 MCP 的 AI 工具调用窗口，官方教程给出的入口是“系统设置 → Local API”：开启鉴权后，复制客户端为所用工具生成的 MCP 地址与请求头配置，再添加到 AI 工具中。完整步骤见 [MCP 接入教程](https://www.bitbrowser.cn/news/how-to-configure-bitbrowser-mcp)。Token 应保存在本地配置中，不能随公开仓库一起提交。
