# Dolphin Anty 免费版有几个环境？套餐、创建次数与交接限制

[返回产品总览](../README.md) · 核验日期：2026-10-27

Dolphin Anty 将环境、代理、扩展和自动化流程放在同一套管理工具里。使用免费版起步时，需要同时看可保留环境数与每月重新创建额度；准备交接环境时，还应把导出和同步权限纳入考虑。

## 官方页面目前存在 3 个与 5 个的差异

本轮打开的[套餐帮助文档](https://docs.dolphin-anty.com/en/personal-cabinet/plans-in-dolphin-anty)写明 Free 为 3 个长期免费环境；[价格页](https://dolphin-anty.com/tarifs/)页尾也写 3 个，但同页部分功能表仍保留“Up to 5”。

本目录按套餐帮助文档记录 3 个，并保留这一差异。新用户规划账号数量时，可以先按 3 个安排；已有账号的实际名额可在客户端套餐界面查看。

## 保存 3 个环境，每月可以重建多少次

套餐帮助页还列出免费档最多 50 个代理、10 个扩展，以及每月 20 次环境重新创建额度；账号内同时保留的环境仍不超过 3 个。删除动作本身不计为一次重新创建，也不会把总名额扩大。

这个限制对频繁换环境的使用方式更重要。长期保留三个固定环境，与每几天删除重建一次，消耗的月度创建额度不同。[环境限制文档](https://docs.dolphin-anty.com/en/working-with-profiles/restrictions-on-working-with-profiles-in-dolphin-anty)进一步解释了超出额度时的处理。

## Starter 与更高档位分别增加什么

套餐文档列出 Starter 的 20～60 个环境选择，并加入 Cookie 导出和环境云同步等能力。若要把正在使用的环境交给其他成员，先把这些交接动作列出来，再对应档位。

公开价格页另列 Base 100 个环境、89 美元/月，Team 300 个环境、159 美元/月；额外用户由选择器配置。这些是月付展示，不能直接与其他产品的年付折算价比较。

## API 适合怎样的工作流

官方[自动化文档](https://docs.dolphin-anty.com/en/api/basic-automation-dolphin-anty)说明了通过接口启动环境、获得自动化连接信息的方式。对于已有程序的团队，应该把所需接口、环境数和成员权限一起放入选型条件。

免费档主要用于少量手动环境；涉及自动化、同步和交接时，选择包含对应权限的档位。这样能在正式编写流程前，把持续费用和使用条件安排清楚。

## 值得与哪些方案一起看

如果需要一个人保留更多免费环境，可以比较[比特浏览器](bitbrowser.md)；如果主要关心长期保留大量环境、每天启动次数有限，可以比较 [ixBrowser](ixbrowser.md)。已经形成 Dolphin 操作流程的团队，则应把现有标签、代理和自动化配置的迁移工作也算进选择。
